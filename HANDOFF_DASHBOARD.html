Walk me through it

About one minute

Open Murmur

Start the normal Murmur editor. You do not need a special smoke tool.

Pick a Flock tab

Each Flock tab is one kind of moving thing. Use a fresh tab if you do not want to replace your current birds.

Click the Bird picture

That picture is also the artwork-import button. The label still says “Bird,” but it accepts smoke and symbols too.

Choose one ZIP

Use the smoke ZIP for a cloud or the quarter-note ZIP for the blue note. Do not unzip it first.

Draw the same route as usual

Enter = comes in. Path = travels. Landing = gathers or rests. Exit = releases and leaves. Murmur switches the four image groups for you.

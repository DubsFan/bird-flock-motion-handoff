# Silver Vortex Smoke

A directly importable 60-frame Murmur identity: 15 flow frames, 15 gather/compress frames, 15 compressed micro-twirl frames, and 15 release/bloom/dissipate/reform frames.

All PNGs use a 2048×1280 RGBA canvas with anchor `(1024, 640)`. Runtime playback uses the authored PNGs directly. The `right` direction field satisfies Murmur's directional metadata; the cloud is approximately bidirectional and may be mirrored by path direction.

# Reversed High-Excursion Wingbeat Specification

The extracted source birds are now treated as **left-facing** and travel from right to left across the frame.

| Element | New setting |
| --- | --- |
| Travel direction | Right-to-left, preserving the slow 10-second passage inside a 12-second loop |
| Hero C upstroke | About ±34° around the original center notch |
| Hero C downstroke | About ±30° around the original center notch |
| Support A/B | 75–85% of hero excursion, offset in phase |
| Joint | Original center-notch pixels stay fixed and composited last |

The effect is a visibly large, continuous wingbeat on the extracted contour. No replacement silhouette, fill, or new linework is introduced.

# Monochromatic Bird Mark Rules

All visible bird marks use exactly one dark marine-blue ink color: `#043A78`. The difference between outer contour, trailing contour, center notch, and inner construction echo comes only from **line width and incompleteness**, never from a second hue, outline color, fill, or opacity treatment.

The intended look is a single continuous hand-drawn ink system: broad confident outer arcs, thinner trailing arcs, and fine incomplete interior echoes. No gradients, shadows, white contour, black body fill, or secondary blue are permitted.

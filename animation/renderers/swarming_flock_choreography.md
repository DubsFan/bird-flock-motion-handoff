# Expanded Swarming Flock Choreography

| Feature | Implementation |
| --- | --- |
| Density | 18 birds using only normalized C/A/B/D source contours. |
| Major path | The leader makes a large right-to-left rise, crest, and fall. |
| Swirl | Upper and lower follower layers travel delayed versions of the leader route while orbiting through 0.8–1.1 visible turns around the group center at the crest. |
| Formation behavior | The swarm opens into two layers during the climb, curls inward at the crest, and closes into a loose leftward wedge before exiting. |
| Motion independence | Every bird uses a distinct phase, flight lag, wingbeat rate, and orbit start position. |
| Boundaries | Orbit strength fades to zero at entry and exit so the loop begins and ends blank. |

The flock remains leftward-facing and uses only previously extracted source-contour assets.

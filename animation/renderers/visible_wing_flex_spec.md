# Visible Wing-Flex Specification

The earlier ±2° flex was too subtle. This pass increases the locked-contour motion without switching to a hinge rig.

| Bird | Flex range | Cycle rate |
| --- | ---: | ---: |
| C hero | ±9.5° around the original center notch | 0.32 cycles/sec |
| A support | ±7.0° around the original center notch | 0.36 cycles/sec |
| B support | ±8.0° around the original center notch | 0.30 cycles/sec |

The two source-pixel wing regions flex in opposite directions with a soft phase offset. The body path stays unchanged. There are no new bird strokes, no fills, and no side-edge pivot.

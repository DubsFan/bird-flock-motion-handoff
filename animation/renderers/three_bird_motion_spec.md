# Three-Bird Motion Test Specification

The first motion test uses only the approved extracted source contours. There is **no synthetic wing reshaping, no flapping, and no rotation around a wing tip**.

| Bird | Locked asset | Motion |
| --- | --- | --- |
| Hero | C source contour | Slow left-to-right shallow upward arc, 2–3% size drift, maximum 3° full-body bank |
| Support A | A source contour | Higher, slower trailing arc, 1–2% size drift, maximum 2° bank |
| Support B | B source contour | Lower, delayed arc, 1–2% size drift, maximum 2° bank |

The six-second passage sits in an eight-second transparent timeline with a 0.75-second blank lead-in and a 1.25-second blank tail. This is a **glide proof**, not a final flock animation.

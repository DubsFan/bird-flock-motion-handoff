# Bird Flock Video Variation Slate

## Visual Read of the Current Swarm

The current 18-bird swarm has three strong foundations worth preserving: the locked source-contour language, a credible density range, and blank alpha at entry and exit. Its principal limitation is that it is still fundamentally one broad pass through the frame. The next videos should therefore differentiate themselves by **formation behavior**, **path geometry**, and **group narrative**, not by changing the artist’s bird marks.

Every variation below should preserve the normalized extracted C/A/B/D contours, one ink color, leftward facing, transparent alpha, and blank loop endpoints.

## Recommended Production Order

1. **Spiral Crest**, because it exercises the requested swirling motion while keeping the existing swarm as a base.
2. **Split and Rejoin**, because it tests whether the group can carry a readable flock narrative.
3. **Murmuration Ribbon**, because it is the strongest reusable background treatment once the group choreography is stable.
4. **Dive and Recovery**, because it adds a more expressive alternative for hero sections.
5. **Horizon Tide**, because it becomes the low-distraction default background loop.

## Shared Acceptance Rules

A variation is accepted only when the browser playback shows a recognizable group-level shape change, every contour preserves its normalized flight direction, no bird crosses the group with a contradictory trajectory, wings remain visibly active but unsynchronized, and the alpha frame is blank at both loop endpoints.
